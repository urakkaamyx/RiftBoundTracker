# Riftbound SVG Symbol Library

Standalone SVG assets for the Riftbound Vault interface.

- `domain_*.svg`: domain aliases intended for filters, analytics, and card metadata.
- `rune_*.svg`: rune payment symbols used in card rules text.
- `energy_*.svg`, `might.svg`, `exhaust.svg`: rules resources and actions.
- `card_type_*.svg`: card classification symbols.
- `rarity_*.svg`: vector rarity gems matching the game's shape and color families.
- `badge_*.svg`: blank slanted keyword badge backgrounds.
- `symbols.json`: stable name-to-file mapping for UI code.

The Riot glyph files are stored locally so the application remains usable offline. Rarity gems and blank keyword badges are local SVG recreations based on the printed card shapes and colors.
